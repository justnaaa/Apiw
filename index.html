File Shelf & Auto Screenshot

Drop file/folder dengan animasi masuk ke Shelf, seret keluar kapan saja, plus pratinjau otomatis 2–3 tangkapan layar terbaru.

Cara Pemasangan

Cukup 3 langkah mudah.

1

Download & Ekstrak ZIP

Klik tombol Download ApiwSetup.zip, lalu ekstrak file tersebut di Windows Explorer. Di dalamnya hanya berisi 1 file ApiwSetup.exe.

2

Jalankan Installer

Klik dua kali ApiwSetup.exe. Jika muncul layar biru Windows SmartScreen, pilih More info → Run anyway.

3

Atur Sesuai Selera

Buka ikon lonceng / System Tray → Settings. Untuk fitur AI Gemini, masukkan API key Anda sendiri di tab AI & Voice.

×

Cara Uninstall

Tutup Apiw dari System Tray → Quit, lalu buka Windows Settings → Apps → Installed apps, cari Apiw dan klik Uninstall.

Pertanyaan & Privasi

Transparan & aman di perangkat Anda.

Apakah perlu API key untuk menjalankan Apiw?

Tidak wajib. Musik, lirik LRCLIB, TodoList + OCR lokal, File Shelf, Pomodoro, Kalender, jadwal Sholat, dan animasi maskot berjalan tanpa API key. API key hanya diperlukan jika Anda ingin memakai asisten AI Gemini/OpenAI.

Apakah API key saya aman?

Di dalam paket installer dan repositori, API key selalu dalam kondisi kosong (""). Saat Anda mengisi API key, data tersebut hanya tersimpan secara lokal di folder konfigurasi komputer Anda sendiri dan tidak dikirim ke pihak lain selain penyedia AI yang Anda pilih.

Apakah saya perlu instal Python atau Node.js secara terpisah?

Jika mengunduh rilis ApiwSetup.zip dari halaman Releases, semua komponen sudah dibundel agar langsung siap pakai di Windows 10/11 64-bit.

Siap pasang Apiw di Windows Anda?

Ringan, bersih, tanpa batasan fitur berbayar, dan sumber terbuka di GitHub.
