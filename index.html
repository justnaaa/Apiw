Fitur Unggulan

Semua hal penting dalam satu tarikan kursor.

Arahkan mouse ke notch di atas layar untuk membuka, atau geser 2 jari di touchpad untuk berpindah slide. Tanpa iklan dan tanpa fitur yang dikunci.

Maskot Apiw Ekspresif

Beruang putih berjaket merah yang berkedip saat idle, melambai saat ada notifikasi, memakai cincin halo emas saat waktu sholat, dan menampilkan ekspresi lelah saat baterai ≤ 20%.

Musik & Lirik Sinkron LRCLIB

Terhubung otomatis ke Spotify, YouTube di Chrome/Edge, dan VLC melalui Windows GSMTC lengkap dengan lirik berjalan real-time dari LRCLIB.

TodoList + Scan OCR Pintar

Klik + Add Task untuk langsung mengetik di tempat, klik tugas mana saja untuk menandai selesai, tombol Clear sekali klik, atau drop gambar/PDF tugas untuk dilist otomatis 1 per 1.

Document Studio & Voice AI

Analisa dokumen Word/Excel/PDF/Scan, revisi teks langsung di Word & Notepad (dengan pratinjau Diff & Undo), export file .docx rapi, serta obrolan suara bahasa Indonesia.

Kalender Mini, Sholat & Fokus

Kartu kalender bulan berjalan, jadwal sholat offline (Kemenag, MWL, dll.) dengan kedipan emas 3×, pengingat minum air, serta timer fokus Pomodoro.

File Shelf & Auto Screenshot

Drop file atau folder ke dalam notch untuk disimpan sementara, seret keluar kapan saja ke aplikasi lain, ditambah pratinjau otomatis 2–3 screenshot terbaru.

Panduan Instalasi

Dari pasang hingga hapus, serba praktis.

Ekstrak, jalankan installer, dan Apiw langsung muncul di tepi atas layar Windows Anda.

  1. 1 Download & Ekstrak ZIP

    Unduh ApiwSetup.zip dari tombol di halaman ini, klik kanan lalu pilih Extract All. Di dalamnya hanya ada 1 file ApiwSetup.exe.

  2. 2 Jalankan Installer

    Klik dua kali ApiwSetup.exe. Jika muncul layar biru Windows SmartScreen, klik More info → Run anyway untuk melanjutkan.

  3. 3 Kustomisasi & AI

    Klik kanan ikon Apiw di System Tray → Settings. Untuk fitur AI Gemini/OpenAI, masukkan API key pribadi Anda di tab AI & Voice.

  4. × Uninstall Bersih

    Tutup Apiw dari System Tray → Quit, buka Windows Settings → Apps → Installed apps, cari Apiw lalu klik Uninstall.

Pertanyaan Umum & Privasi

Transparan & aman di perangkat Anda.

Apakah wajib memiliki API key untuk memakai Apiw?

Tidak wajib. Fitur musik, lirik sinkron LRCLIB, TodoList + OCR lokal, File Shelf, Pomodoro, Kalender, jadwal Sholat, serta animasi maskot berjalan langsung tanpa API key. API key hanya dibutuhkan jika Anda ingin memakai asisten dokumen & suara berbasis AI Gemini/OpenAI.

Apakah API key dan dokumen saya aman?

Sangat aman. Di dalam paket installer maupun repositori GitHub, API key selalu kosong (""). Saat Anda mengisi API key sendiri, kunci hanya tersimpan di folder konfigurasi lokal PC Anda (%APPDATA%\apiw) dan tidak pernah dikirim ke pihak lain selain penyedia AI yang Anda pilih.

Pemutar musik apa saja yang didukung?

Semua pemutar yang terintegrasi dengan Windows Media Overlay (GSMTC), termasuk Spotify Desktop, Apple Music, VLC, serta YouTube atau SoundCloud yang diputar di Chrome, Edge, maupun Firefox.

Bagaimana cara menghapus Apiw beserta data lokalnya?

Quit Apiw dari System Tray, lalu Uninstall lewat Windows Settings → Apps. Jika ingin membersihkan seluruh pengaturan dan daftar To-Do tersimpan, hapus juga folder %APPDATA%\apiw.

Siap pasang Apiw di Windows Anda?

Ringan, interaktif, semua fitur terbuka tanpa langganan, dan tersedia gratis di GitHub.
